# AI Hologram Tutor

An AI-based interactive system that simulates conversations with historical figures using avatars.

## Features
- Chat with AI personalities (Einstein, Gandhi, etc.)
- Voice-based responses (TTS)
- Talking avatar simulation
- Interactive learning interface

## Tech Stack
- Frontend: React (Vite)
- Backend: Flask
- AI Model: Ollama (LLM)
- TTS: Coqui TTS
- Avatar: SadTalker

## Architecture
User → LLM → Text → TTS → Audio → Avatar → Video Output

## Status
Project structure completed. Full integration in progress.
